# Sources and shortcodes

Short paraphrases only; no article text is copied. "Origin" separates what a source *supplies* from what the **author chose or derived**.
Per-parameter use, with the full link beside each row, is in [PARAMETERS.md](PARAMETERS.md). A numeric value chosen by the author with a stated rationale is legitimate provenance for a scenario value,
but it is **not** a literature measurement. Revision `literature_parameters_20261111` rev2 (2026-11-12) adopted published equations or model inputs for a limited set of fields (listed in PARAMETERS.md); none is a Jornada field calibration.

## Revision summary (`literature_parameters_20261111` rev2)

* **Changed numbers** (full table in PARAMETERS.md): PROGLA diameter and height allometry (Northup 2005 Table 7; McClaran 2013 Table 2 *P. velutina* proxy), PROGLA live fraction and k (Northup 2005 Table 1), BOER intrinsic rate and clonal daughter size/threshold (pinned STEPWAT2 `bogr` *B. gracilis* model input; threshold author-derived), soil field capacity 0.23 (FAO-56).
* **Not changed, with gaps**: mature masses, mean lifespans (BOER 15 yr stands against 2–4 yr field clump persistence; PROGLA 80 yr vs maxima only), all other growth, mortality, disturbance, reproduction-probability numbers.
* The saved initial-vegetation preview keeps using the frozen earlier catalog `preview/species_at_initialization.json`.

## Distinction summary

* **Literature values used (with proxy qualifiers):** NOAA normals; Vito & Sala β; Northup 2005 (diameter law, live fraction); McClaran 2013 (*P. velutina* height proxy); STEPWAT2 `bogr` model inputs (related grass); Belovitch grass demand (descriptive reanalysis); Peterson & Neofotis conditional seedling demand; Carsel & Parrish θr/θs; FAO-56 θ_FC.
* **Derivations by the author:** layer fractions, support k, Weibull scales, lognormal parameters, initial biomass/height, expected counts, unit conversions, algebraic inversion of the Northup law and composition of the McClaran height law, `clonal.min_agb_dry_kg`, monthly rain disaggregation.
* **User targets:** covers, diameters, root-radius range.
* **Author hypotheses (uncalibrated):** everything else, as listed in PARAMETERS.md. No field validation is claimed.
