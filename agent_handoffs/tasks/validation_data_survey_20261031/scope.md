Codex performs public-data research and documentation. No implementation writer
or Claude session is assigned. Automatic collaboration remains enabled.

Allowed writes: this new task directory; `docs/validation-data.md`; a link in
`README.md`; Codex-owned root handoff state, prompt, review, verification,
decisions and project brief. Preserve root `AGENTS.md`, all numerical code,
locks, prior task archives, simulations and upstream repositories.

Read scope: LEAF instructions, scientific design, current method/trait guide,
existing literature provenance and manifests; public primary dataset records,
metadata, methods and bounded public samples. Do not share private source files,
contact investigators, install packages, or run/calibrate models.

Deliver: a prioritized, linked inventory for Jornada grass/mesquite biomass,
individual geometry, depth-resolved water, transpiration/ET, weather and relevant
experiments. Identify measured versus derived quantities, units, resolution,
access actually verified, calibration/validation separation and missing evidence.
Do not call a catalog listing a verified download or infer complete woody mass
from seasonal production measurements. Record retrieval failures honestly.

Acceptance: primary references support inventory entries; versions are pinned
where actually inspected; method mismatch and access limits are explicit; local
links resolve; runtime, root instructions and accepted archives match baseline.
